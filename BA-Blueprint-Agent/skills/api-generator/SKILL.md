# Skill: API Generator

## Mục tiêu

Mô tả contract tích hợp đủ rõ cho consumer, implementer và tester.

## Đầu ra

API ID, purpose, method/path hoặc event, authentication, authorization, headers, request schema, response schema, status/error codes, idempotency, pagination/filtering, rate limit và versioning.

## Quy tắc

API chỉ được sinh từ use case và data model đã có. Nêu rõ dữ liệu nhạy cảm, validation boundary và backward compatibility.

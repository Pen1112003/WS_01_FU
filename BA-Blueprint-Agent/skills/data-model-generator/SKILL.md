# Skill: Data Model Generator

## Mục tiêu

Xác định dữ liệu nghiệp vụ, quan hệ, vòng đời và quyền sở hữu để hỗ trợ behavior đã phân tích.

## Đầu ra

Entity catalogue, attribute name/type/requiredness, identifier, relationship, cardinality, validation, status lifecycle, data owner, retention, classification và audit need.

## Kiểm tra

Mỗi field phải phục vụ một requirement hoặc rule. Không tạo entity chỉ vì thói quen kỹ thuật; phân biệt source of truth với dữ liệu dẫn xuất.

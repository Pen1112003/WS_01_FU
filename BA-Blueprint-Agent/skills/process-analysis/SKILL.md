# Skill: Process Analysis

## Mục tiêu

Mô hình hóa current state và future state để tìm điểm nghẽn, kiểm soát, ngoại lệ và cơ hội cải tiến.

## Đầu vào

Process description, actor, system, business rule, SLA và các exception đã biết.

## Thực hiện

- Mô tả trigger, input, activity, decision, output và owner.
- Tách manual step, automated step và handoff giữa các vai trò.
- Ghi nhận bottleneck, duplicate entry, failure point và control point.
- Đề xuất future state chỉ dựa trên outcome và constraint đã xác nhận.

## Đầu ra

Bảng current/future state, process rules, exception catalogue, dependency list và câu hỏi cần xác nhận.
